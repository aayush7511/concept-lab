# LLM exercise separation audit

Scope: 122 lessons, 366 Predict/Modify/Practice stages (113 coding and 9 conceptual lessons).

## Findings and corrections

- The nine conceptual lessons already have separate scenarios after the earlier duplication fix.
- All 113 coding Practice tasks used a generic list wrapper around Modify's operation. They have been replaced with independently specified applications and explicit expected-value fixtures.
- Predict's worked input was also present in Modify examples and grading cases. Modify now uses different supplied cases. The mathematical concept remains shared intentionally.
- One Parameter exercise statement did not describe its tuple return value accurately; its requirement now matches the checked behavior.
- Old attempts at replaced tasks are archived with their original question; they do not count as passing a new task. Other stage progress and tutor conversations are retained.

## Checks

Automatic checks detect exact question/task duplication, identical reference programs, generic solve-many wrappers, repeated Predict/Modify examples, missing transfer metadata, and insufficient Practice fixtures. There are 0 structural findings remaining. These checks do not prove semantic independence. The task-by-task application design was reviewed in the authored transfer specifications; execution verification is performed separately with npm run verify:llm.

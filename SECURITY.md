# Security

This beta is intended for one local user on a trusted macOS computer. It is not
a multi-user hosted service. Do not bind the application to a public interface.

Do not post access tokens, refresh tokens, authorization callback URLs,
`.local/` files, real medical records, or personal project contents in public
issues. Report suspected vulnerabilities privately to the maintainer through
the distribution channel you received this app from. A public vulnerability
intake address has not been established yet.

If a connection may be compromised, disconnect Concept Lab in ChatGPT settings
and reconnect only after addressing the cause. Include a minimal synthetic
reproduction and affected version in reports, without credentials.
